## Что делает

Добавляет операцию **"Группа"** в карточку "Выноски" DesignTools.

Объединяет выравнивание по оси и распределение с шагом в одну операцию:
- **Вертикально:** все выноски получают общий X (от первой), разносятся по Y с заданным шагом
- **Горизонтально:** все выноски получают общий Y (от первой), разносятся по X с заданным шагом

Шаг задается интерактивно двумя точками (как в существующей операции "Шаг").

## Поддержка

- MultiCAD-выноски (reflection, пре-селекшен)
- Teigha MLeader (стандартный документ + транзакция)

## Валидация

- `dotnet build SpecStudioParser.sln -c Debug` — 0 ошибок
- Выбрать >=2 выносок, "Группа", "Вертикально", указать шаг двумя точками, проверить общий X и равный шаг по Y
- Аналогично для "Горизонтально" с проверкой общего Y и шага по X
